# Заменки — Android илова

Режа, заказ ва назорат бир жойда. Маълумотлар фақат телефонингизда сақланади, интернет керак эмас.

## Бўлимлар
1. **Бош саҳифа** — бугунги сана, бугунги режа, янги заказлар сони, «Янги заказ» ва «Режа қўшиш» тугмалари.
2. **Режа** — кунлик вазифалар, ‹ › билан кунларни алмаштириш, сана устига босиб календарни очиш. Бажарилган вазифалар автоматик чизилади ва рўйхат пастига тушади.
3. **Заказлар** — рақами, мижоз исми, стол, таомлар, сони, умумий нарх, тўлов тури (Нақд/Карта/Онлайн), ҳолати (Янги → Тайёрланмоқда → Тайёр → Етказилди). Ҳолатни «▶» тугмаси билан тез ўзгартириш мумкин, заказ устига босиб таҳрирлаш ёки ўчириш мумкин. Ҳолат бўйича фильтр бор.
4. **Эслатма** — матн, сана ва вақт танланади, вақти келганда телефонга билдиришнома келади.
5. **Статистика** — бугунги вазифалар ва заказлар, тўлов турлари бўйича суммалар, ҳолатлар бўйича жами, охирги 7 кун.

## APK олиш (GitHub орқали)

Агар `zametka` репозиторийингиз аввалги версия билан бор бўлса:

1. Репозиторийда **Add file → Upload files** босинг.
2. Архивни очиб, **ичидаги ҳамма файлларни** (шу жумладан `.github` папкаси ва `app/zamenki.jks`) ёзиб юборинг (eski файллар алмашади).
3. **Commit changes** босинг. Сборка ўзи бошланади.
4. **Actions** → охирги сборкани очинг → пастда **Artifacts** → `Zamenki-apk` юклаб олинг (ичида `app-debug.apk`).
5. APK файлни телефонга юборинг ва ўрнатинг.

Эслатма: илова номи ва ID ўзгарган (`com.zamenki.app`), шунинг учун у эски «Мои задачи» иловасининг ўрнига эмас, **алоҳида** ўрнатилади. Эски иловани хоҳласангиз ўчириб ташланг.

`app/zamenki.jks` — иловани имзоловчи калит. Уни ўчирманг: шу калит туфайли кейинги версиялар эски устига маълумотларни йўқотмасдан ўрнатилади.

## Эслатмалар ҳақида
- Android 13 ва юқорида биринчи эслатма қўшишда билдиришномаларга рухсат сўралади — «Рухсат бериш» ни босинг.
- Эслатма вақтдан бир неча дақиқа кечикиб келиши мумкин (Android батареяни тежаш учун шундай қилади).

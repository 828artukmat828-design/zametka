# Мои задачи — Android-приложение

Простое приложение для планов и задач. Данные хранятся только в телефоне, интернет не нужен.

Что умеет:
- добавлять задачи и планы;
- отмечать галочкой «сделано» (текст зачёркивается) и снимать галочку;
- удалять задачу кнопкой ✕ (с подтверждением);
- удалять сразу все выполненные;
- показывать счётчик «Выполнено: N из M»;
- помнить задачи после закрытия приложения.

## Как получить APK (бесплатно, через GitHub)

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Нажмите «+» → «New repository». Назовите, например, `MyTasks`. Выберите **Private** (приватный). Нажмите «Create repository».
3. Распакуйте архив `MyTasks.zip` на компьютере.
4. В новом репозитории нажмите «uploading an existing file» и перетащите в окно **всё содержимое** папки `MyTasks`, включая папку `.github` (она может быть скрытой).
   - Если папка `.github` не загрузилась: нажмите «Add file» → «Create new file», в поле имени впишите `.github/workflows/build.yml`, вставьте туда содержимое файла `build.yml` и сохраните.
5. Нажмите «Commit changes». Сборка запустится сама.
6. Откройте вкладку **Actions**. Дождитесь зелёной галочки (2–5 минут).
7. Нажмите на завершённую сборку, внизу в разделе **Artifacts** скачайте `MyTasks-apk`. Это zip: внутри лежит `app-debug.apk`.
8. Отправьте `app-debug.apk` на телефон (Telegram, почта, USB).

## Установка на телефон

1. Откройте файл `app-debug.apk` на телефоне.
2. Если телефон спросит, разрешите установку из этого источника (Настройки → «Установка неизвестных приложений»).
3. Нажмите «Установить». Если Play Protect предупредит о неизвестном приложении, выберите «Всё равно установить»: это ваше личное приложение.

## Если сборка покраснела (ошибка)

Откройте красную сборку в Actions, скопируйте текст ошибки и пришлите мне: я подскажу, что исправить.

## Для тех, кто работает в Android Studio

Откройте папку проекта в Android Studio и нажмите Build → Build APK(s).
